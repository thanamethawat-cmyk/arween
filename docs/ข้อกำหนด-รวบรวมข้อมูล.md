# ข้อกำหนด: รวบรวมข้อมูล

**ต้นทางผลิตภัณฑ์:** [พิมพ์เขียว-ARWEEN.md](./พิมพ์เขียว-ARWEEN.md) · [ข้อมูลหลัก-ARWEEN.md](./ข้อมูลหลัก-ARWEEN.md)

หน้าที่ที่ 1 ของทีม AI — เก็บหลักฐานการทำงานในโปรเจกต์ส่วนรวม

---

## ต้องบันทึกให้ครบ

ทุกบันทึกหลักฐานต้องมีฟิลด์เหล่านี้:

| ฟิลด์ | ความหมาย | ตัวอย่าง |
|-------|----------|----------|
| ใครทำ (actorId) | รหัสผู้ทำงาน | user-001 |
| ทำอะไร (action) | รายละเอียดการกระทำ | แก้ไขงาน "ออกแบบหน้าจอ" |
| เมื่อไหร่ (occurredAt) | วันเวลาที่เกิด | 2026-09-02T14:30:00 |
| มาจากไหน (source) | ประเภทแหล่งข้อมูล | งาน, ความเห็น, เอกสาร |
| โปรเจกต์ไหน (projectId) | โปรเจกต์ที่เกี่ยวข้อง | project-demo-001 |

---

## ขอบเขตที่รับได้

- พื้นที่โปรเจกต์ส่วนรวมเท่านั้น (ตามข้อเสนอ: Project Workspace)
- งานที่สร้างหรืออัปเดตในโปรเจกต์
- ความเห็นในโปรเจกต์
- ลิงก์เอกสารที่ผูกกับโปรเจกต์ (เช่น Google Docs / Sheets / Drive)

ข้อมูลเหล่านี้คือ **Audit Trail** สำหรับการให้คะแนนและโต้แย้งภายหลัง

---

## ขอบเขตที่ห้ามรับ

- ข้อความส่วนตัว (DM) — ตาม Data Privacy ในข้อเสนอ
- แชทส่วนตัว
- อีเมลส่วนตัว
- ข้อมูลนอกโปรเจกต์

ระบบต้องปฏิเสธข้อมูลประเภทข้อความส่วนตัวตั้งแต่ฝั่งเซิร์ฟเวอร์ ไม่ใช่แค่ซ่อนปุ่มบนหน้าจอ

---

## ผลลัพธ์ที่ส่งมอบ

- บันทึกหลักฐานเรียงตามเวลา
- หน้าแสดงประวัติหลักฐานของโปรเจกต์
- ไม่มีการลบหลักฐาน (เก็บถาวรเพื่อตรวจสอบ)
