# สถานะแพลตฟอร์ม ARWEEN

**วันที่สำรวจ:** 6 กันยายน 2026  
**ต้นทางผลิตภัณฑ์:** [พิมพ์เขียว-ARWEEN.md](./พิมพ์เขียว-ARWEEN.md)

เอกสารนี้สรุปว่าสร้างอะไรแล้วในโค้ดจริง ไม่ใช่แค่ในข้อเสนอ  
ภาษาที่ใช้: ไทย กึ่งทางการ เข้าใจง่าย

## ภาพรวมสั้น

แพลตฟอร์มมี **สองชั้นในที่เก็บโค้ดเดียวกัน** ที่ยังไม่รวมเป็นระบบเดียว

| ชั้น | สถานะ | ใช้ทำอะไร |
|------|--------|-----------|
| **เวอร์ชันต้นแบบที่เปิดใช้จริง** | ใช้งานได้ | Firebase Auth + Firestore + Gemini บน Cloud Run |
| **ชั้นองค์กรรอบถัดไป** | มีโค้ดแล้ว แต่ไม่ได้เป็นเส้นทางหลัก | Prisma / PostgreSQL, NextAuth, เชิญสมาชิก, หลักฐาน, แจ้งเตือน, ข้อโต้แย้ง |

ลิงก์ที่ deploy: [arween-app บน Cloud Run](https://arween-app-619248313782.asia-southeast1.run.app)

## 1. สิ่งที่ใช้งานได้จริงตอนนี้ (Firebase + Gemini)

ผู้ใช้เข้าด้วยบัญชี Google หรืออีเมล แล้วทำงานบนโปรเจกต์ของตนเอง

| รายการ | สถานะ | อยู่ที่ไหน |
|--------|--------|-----------|
| เข้าสู่ระบบ Google / อีเมล | ทำแล้ว | `context/auth-context.tsx`, `app/login` |
| รายการโปรเจกต์ + สร้างโปรเจกต์ | ทำแล้ว | `app/page.tsx`, `lib/firestore-service.ts` |
| แดชบอร์ดความคืบหน้า % และคะแนนสะสม | ทำแล้ว | หน้าแรกและหน้ารายละเอียดโปรเจกต์ |
| บันทึกงานรายวัน (หลักฐาน) | ทำแล้ว | หัวข้อ, สิ่งที่ทำ, ปัญหาที่ติด |
| Invisible AI Observer ให้คะแนน 0–10 พร้อมเหตุผล | ทำแล้ว | `lib/gemini.ts` → `/api/ai/evaluate-log` |
| สรุปภาพรวมทีมจากบันทึกงาน | ทำแล้ว | `/api/ai/summarize-project` |
| แชทกับ AI ในบริบทโปรเจกต์ | ทำแล้ว | `/api/ai/chat` |
| ลิงก์เอกสาร Google (Docs / Sheets / Drive / Slides / Meet) | ทำแล้ว | คอลเลกชัน `google_tools` ใน Firestore |
| แสดงจุดติดขัด (blockers) | ทำแล้ว | บันทึกงาน + สรุปโปรเจกต์ |
| Deploy บน Cloud Run | ทำแล้ว | `asia-southeast1` |

**ข้อจำกัดของชั้นนี้**

- ข้อมูลแยกรายผู้ใช้ (`users/{uid}/projects`) — ยังไม่ใช่โปรเจกต์ทีมที่สมาชิกหลายคนเข้าด้วยกัน
- ความคืบหน้า % มาจากค่าที่ AI เสนอต่อบันทึก ไม่ได้คำนวณจากน้ำหนัก Milestone / KPI
- ยังไม่มีวัตถุประสงค์ / เป้าหมายงานส่งมอบ / ตัวชี้วัดในฐานข้อมูล
- สัดส่วนผลงานรายบุคคลรวม 100% ยังไม่มีในโค้ดชั้นนี้
- สมัครบัญชีได้จากหน้าเข้าสู่ระบบ — ยังไม่บังคับลิงก์เชิญบนเส้นทางที่ deploy

## 2. สิ่งที่มีโค้ดแล้ว แต่ยังไม่ใช่เส้นทางหลัก (Prisma)

โครงองค์กรมีครบในสคีมาและหน้าบางหน้า แต่ล็อกอินหลักของแอปใช้ Firebase ไม่ใช้ NextAuth  
หน้าเหล่านี้จึงยังไม่ต่อกับโปรเจกต์ Firestore ที่ผู้ใช้สร้างบนหน้าแรก

| รายการ | สถานะ | อยู่ที่ไหน |
|--------|--------|-----------|
| สคีมาองค์กร (User, Project, สมาชิก, งาน, เอกสาร, คะแนน) | มีแล้ว | `prisma/schema.prisma` |
| คำเชิญสมาชิก (ลิงก์ครั้งเดียว หมดอายุ 7 วัน) | มีแล้ว | `lib/invite-service.ts`, `app/invite/[token]` |
| NextAuth (อีเมล + Google แบบต้องมีคำเชิญ) | มีแล้ว | `lib/auth.ts` — **ยังไม่ต่อกับ `Providers`** |
| เก็บหลักฐาน (EvidenceEvent) | มีแล้ว | `server/collect.ts`, `app/projects/[id]/evidence` |
| แจ้งเตือน 3 ประเภท (สรุปรายสัปดาห์ / ปั่นคะแนน / ข้อโต้แย้ง) | มีแล้ว | `server/notify.ts` |
| ให้คะแนน + ยืนยันโดยหัวหน้า + ข้อโต้แย้ง | มีแล้วบางส่วน | `server/evaluate.ts` — **ยังไม่เรียก Gemini** |
| งาน (WorkItem) + เอกสารในฮับโปรเจกต์ | มีคอมโพเนนต์แล้ว | `components/project-hub-client.tsx` — **ยังไม่มีหน้าไปเรียกใช้** |
| Validation ด้วย Zod | มีแล้ว | `types/schemas.ts` |

## 3. สี่หน้าที่ของทีม AI — เทียบกับของที่สร้างแล้ว

| หน้าที่ | ในเวอร์ชันที่เปิดใช้จริง | ในชั้น Prisma |
|---------|--------------------------|---------------|
| 1. รวบรวมข้อมูล | บันทึกงานรายวันในโปรเจกต์ | หลักฐานจากงาน / ความเห็น / เอกสาร / อัปเดตสถานะ |
| 2. แจ้งเตือน | แสดง blockers ในหน้าโปรเจกต์; กฎปั่นคะแนนอยู่ในคำสั่ง AI | สร้างการแจ้งเตือน 3 ประเภทได้ — ยังไม่ส่งอัตโนมัติตามตาราง |
| 3. อำนวยความสะดวก | รวมสถานะ ลิงก์ Google แชท AI | ฮับงาน+เอกสารมีโค้ด แต่ยังไม่ผูกหน้า |
| 4. ประเมินแบบเป็นกลาง | Gemini ให้ Impact Score + เหตุผล + สรุปทีม | บันทึกคะแนนและข้อโต้แย้งได้ แต่ยังไม่เรียก Gemini |

รายละเอียดขอบเขต: [ทีม-AI-ขอบเขตหน้าที่.md](./ทีม-AI-ขอบเขตหน้าที่.md)

## 6. กองไฟล์หลักที่สร้างแล้ว

```
app/
  page.tsx                          รายการโปรเจกต์ (Firestore)
  login/                            เข้าสู่ระบบ Firebase
  projects/[id]/                    พื้นที่โปรเจกต์ + AI
  projects/[id]/evidence|evaluation|notifications   ชั้น Prisma (NextAuth)
  invite/[token]/                   รับคำเชิญ
  api/ai/                           evaluate-log, summarize-project, chat
  api/auth/[...nextauth]/           NextAuth (ชั้นองค์กร)

components/
  project-view-client.tsx           หน้าโปรเจกต์ที่ใช้งานจริง
  invite-manager.tsx / invite-accept-client.tsx
  evaluation-client.tsx / evidence-client.tsx / notifications-client.tsx

lib/
  firebase.ts, firestore-service.ts, gemini.ts
  auth.ts, invite-service.ts, prisma.ts

server/                             collect, evaluate, notify, facilitate, invite
prisma/schema.prisma
docs/                               พิมพ์เขียวและข้อกำหนดผลิตภัณฑ์
```

## สรุปหนึ่งย่อหน้า

ตอนนี้ ARWEEN มีเวอร์ชันต้นแบบที่เปิดใช้ได้จริง: เข้าสู่ระบบ สร้างโปรเจกต์ บันทึกงาน ให้ Gemini ให้คะแนนพร้อมเหตุผล สรุปทีม และผูกลิงก์เอกสาร Google ชั้นองค์กร (เชิญสมาชิก หลักฐานหลายคน ข้อโต้แย้ง การแจ้งเตือน) มีโค้ดแล้วแต่ยังไม่ต่อกับเส้นทางที่ผู้ใช้เปิดอยู่ และเกณฑ์เปอร์เซ็นต์ 2 มิติที่ผูก Milestone / KPI ยังอยู่ที่เอกสาร ยังไม่ลงฐานข้อมูล
