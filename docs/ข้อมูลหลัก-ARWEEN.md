# ข้อมูลหลักของ ARWEEN

**บัญชีข้อมูลที่เอกสารและโปรแกรมต้องอ้างตรงกัน**  
ต้นทางผลิตภัณฑ์: [พิมพ์เขียว-ARWEEN.md](./พิมพ์เขียว-ARWEEN.md)

ภาษาที่ใช้: ไทย กึ่งทางการ เข้าใจง่าย  
รหัสในระบบคอมพิวเตอร์เก็บเป็นภาษาอังกฤษได้ แต่ความหมายต้องอ่านเป็นภาษาไทยได้ชัดเจน

## 1. ค่ารหัสที่ใช้ซ้ำ

### 1.1 สถานะโปรเจกต์

| รหัสในระบบ | ความหมายภาษาไทย | หมายเหตุ |

| IN_PROGRESS | กำลังทำ | |
| COMPLETED | เสร็จแล้ว | |
| ACTIVE | กำลังใช้งาน | ใช้ในโครงองค์กรรอบถัดไป (Prisma) ใกล้เคียงกับ IN_PROGRESS |

### 1.8 คะแนนผลกระทบ (Impact Score)

| ช่วงคะแนน | ความหมายภาษาไทย |
|-----------|------------------|
| 0–2 | ตอบรับทั่วไป ไม่ช่วยงาน และ/หรือ ไม่ผูกกับตัวชี้วัด |

| 9–10 | ปลดล็อก Blocker สำคัญของ KPI หลัก หรือมีผลสูงมากต่อความสำเร็จโปรเจกต์ |

## 2. ข้อมูลหลักและฟิลด์สำคัญ

### 2.1 ผู้ใช้

| หัวข้อ | รายละเอียด |
|--------|------------|
| คืออะไร | คนที่เข้าใช้ระบบ |

### 2.2 โปรเจกต์

| หัวข้อ | รายละเอียด |
|--------|------------|

| เก็บที่ไหนตอนนี้ | Firestore ภายใต้ผู้ใช้แต่ละคน |

### 2.3 โครงเป้าหมายโครงการ (Anchor Framework)

| หัวข้อ | รายละเอียด |
|--------|------------|
| คืออะไร | ชุดวัตถุประสงค์ (Objectives), เป้าหมายงานส่งมอบ (Milestones), และตัวชี้วัด (KPIs) ที่เป็นตัวตั้งหลักของการคำนวณเปอร์เซ็นต์ |
| ฟิลด์สำคัญของวัตถุประสงค์ | ชื่อ, คำอธิบาย, ค่าน้ำหนัก (Weight) |

| ฟิลด์สำคัญของ KPI | ชื่อ, หน่วยวัด, ค่าเป้าหมาย, ค่าปัจจุบัน, ค่าน้ำหนัก, สถานะ, อ้างอิง Milestone |

## 3. กฎที่ผูกกับข้อมูลหลัก

1. **ห้ามเก็บข้อความส่วนตัว** — ระบบเก็บได้เฉพาะงานในพื้นที่โปรเจกต์ส่วนรวม  
2. **คะแนนต้องมีเหตุผลและผูกเป้าหมาย** — ห้ามมี Impact Score ลอย ๆ โดยไม่อธิบาย และควรอ้าง Objectives / Milestones / KPIs  
3. **บันทึกงานคือหลักฐาน ไม่ใช่ตัวตั้งคะแนน** — ปริมาณข้อความไม่ใช่เกณฑ์เปอร์เซ็นต์  
4. **ความคืบหน้าโครงการรวมคำนวณจากน้ำหนักแผนงาน** — เมื่อ Deliverable / KPI สำเร็จ  
5. **สัดส่วนผลงานรายบุคคลรวมได้ 100%** — แปลงจาก Impact Score ของสมาชิกในรอบนั้น  
6. **ลิงก์เชิญใช้ครั้งเดียว** — หมดอายุภายใน 7 วัน  
7. **ระบบไม่จ่ายโบนัสเองในเวอร์ชันต้นแบบ** — หัวหน้าหรือฝ่ายบุคคลเป็นผู้ตัดสิน  
8. **งานเบื้องหลังที่มีผลจริงต่อตัวชี้วัด ให้คะแนนสูงได้** — ไม่ดูแค่ว่างานนั้นคนเห็นง่ายหรือไม่  
9. **ห้ามปั่นคะแนนด้วยกิจกรรมที่ไม่มีผลต่อ KPI** — Agent 3 ตั้งธงและระงับน้ำหนัก

สถานะว่าสร้างอะไรแล้วในโค้ด: [สถานะแพลตฟอร์ม.md](./สถานะแพลตฟอร์ม.md)

## 5. สรุปสั้น

ข้อมูลหลักของ ARWEEN คือชุดคำจำกัดความร่วมกันของสถานะ บทบาท ประเภทข้อมูล โครงเป้าหมายโครงการ และกฎการใช้ข้อมูล โดยเฉพาะเกณฑ์เปอร์เซ็นต์ 2 มิติ เพื่อให้ทุกคนในทีมพูดถึงสิ่งเดียวกัน และให้โปรแกรมเก็บข้อมูลสอดคล้องกับพิมพ์เขียวผลิตภัณฑ์
