# ข้อกำหนด: เชิญสมาชิกเข้าโปรเจกต์

**ต้นทางผลิตภัณฑ์:** [พิมพ์เขียว-ARWEEN.md](./พิมพ์เขียว-ARWEEN.md) · [ข้อมูลหลัก-ARWEEN.md](./ข้อมูลหลัก-ARWEEN.md)

ARWEEN ไม่เปิดให้สมัครบัญชีเอง พนักงานเข้าทีมได้เฉพาะลิงก์เชิญจากหัวหน้าโปรเจกต์หรือผู้ดูแลระบบ

---

## โฟลว์หลัก

1. หัวหน้าสร้างโปรเจกต์ (หรือใช้โปรเจกต์ที่มีอยู่)
2. หัวหน้ากรอกอีเมลพนักงาน แล้วสร้างลิงก์เชิญ
3. พนักงานเปิดลิงก์ `/invite/[token]`
4. พนักงานเข้าด้วยบัญชี Google องค์กร
5. ระบบตรวจว่าอีเมลตรงกับคำเชิญ แล้วเพิ่มเป็นสมาชิกโปรเจกต์

---

## กฎ

| กฎ | รายละเอียด |
|----|------------|
| ห้ามสมัครสาธารณะ | หน้า `/register` ส่งไปหน้าเข้าสู่ระบบพร้อมข้อความว่าต้องมีลิงก์เชิญ |
| อีเมลต้องตรง | อีเมลจาก Google ต้องตรงกับอีเมลในคำเชิญ (ไม่สนตัวพิมพ์เล็กใหญ่) |
| ใช้ครั้งเดียว | ลิงก์ที่ใช้รับแล้วใช้ซ้ำไม่ได้ |
| หมดอายุ | ลิงก์ใช้ได้ 7 วันนับจากวันที่สร้าง |
| ผู้สร้างลิงก์ | เฉพาะหัวหน้าโปรเจกต์ (`lead`) หรือผู้ใช้บทบาท `LEAD` / `ADMIN` |

---

## การเข้าสู่ระบบ

- **บัญชีที่มีรหัสผ่าน** (เช่น บัญชีสาธิตแอดมิน): เข้าที่ `/login` ด้วยอีเมลและรหัสผ่าน
- **สมาชิกใหม่**: ต้องมีลิงก์เชิญ แล้วเข้าด้วย Google Workspace
- **บัญชี Google ที่มีอยู่แล้วในระบบ**: เข้าที่ `/login` ด้วยปุ่ม Google ได้ โดยไม่สร้างโปรเจกต์เอง

---

## Data Privacy (ตามข้อเสนอ)

- ประมวลผลเฉพาะพื้นที่โปรเจกต์ส่วนรวม
- ไม่เข้าถึงหรือวิเคราะห์ข้อความส่วนตัว (Direct Messages)
- ใช้คะแนนประกอบการตัดสินของหัวหน้า ไม่จ่ายเงินอัตโนมัติใน MVP
